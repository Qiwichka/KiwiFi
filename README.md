# KiwiFi

**Сайт:** https://kiwi-fi.vercel.app · **Android:** [последний APK](https://github.com/Qiwichka/KiwiFi/releases/latest)

Музыкальный плеер: свои треки с диска, облако и SoundCloud. Веб-приложение,
позже — Android-клиент.

## Запуск

```
node tools/serve.js
```

Открыть `http://localhost:5180/app.html`.

**Двойным кликом по `app.html` не откроется** — скрипты подключены как
ES-модули, а по протоколу `file://` браузер их запрещает. Только через http.

## Что уже работает

- добавление файлов кнопкой и перетаскиванием в окно
- воспроизведение, перемотка, громкость, вперемешку, повтор
- экраны: Главная, Поиск, Библиотека, Плейлисты, Очередь
- плейлисты: создать, переименовать в заголовке, удалить, добавить трек по «+»
- **у каждого плейлиста свой живой фон** — четыре сцены на WebGL
- управление с экрана блокировки и кнопок на наушниках
- раскладка подстраивается под телефон: боковая колонка уезжает в нижние вкладки

## Чего ещё нет

Библиотека живёт в памяти и **пропадает при перезагрузке** — хранилище это
фаза 3. Дальше по плану: SoundCloud, облако, оффлайн, Telegram-импорт, APK.

## Устройство

```
app.html              разметка и ловушка ошибок загрузки
assets/css/app.css    раскладка и тема
assets/js/
  app.js              экраны, навигация, плеер
  bg.js               дирижёр фона: держит сцены и раздаёт им кадры
  sky.js              сцена «небо с облаками»   (шейдер из saittest)
  grass.js            сцена «поле травы»        (шейдер из saittest)
  reflect.js          сцена «глубина»           (шейдер из saittest)
tools/serve.js        локальный сервер с поддержкой Range
```

Чистый JS с ES-модулями. **Ни бандлера, ни зависимостей** — как в Qiwigram,
finan и nokla3310.

## Живой фон

Шейдеры перенесены из проекта `saittest` (компоненты Originkit). React там был
только обёрткой вокруг канваса, поэтому осталась чистая математика.

Фон намеренно придушен: полноэкранный шейдер жрёт батарею, поэтому кадры
режутся до 30, при сворачивании окна цикл встаёт совсем, а если WebGL нет —
под канвасами лежит статичный градиент и приложение работает как ни в чём
не бывало.

Читаемость текста держится на вуали `--dim` поверх картинки. У каждой сцены
своя: яркому лугу нужно 0.40, тёмной ночи хватает 0.24.

## Отладка

Без бандлера и sourcemap отладка держится на трёх вещах:

- `window.__kiwi` — состояние, плеер и фон из консоли браузера
- `tools/_client.log` — шаги загрузки, страница шлёт их сама
- сторож на 10 секунд: если приложение не запустилось, покажет что случилось
  и докуда дошло, вместо пустого экрана

## Лицензии

Шейдеры фона — компоненты Originkit, взяты из личного проекта `saittest`.
